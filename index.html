에이전트 명령어 모음집

Codex 10개 + Claude Code 20개. 명령어 설명과 붙여넣기 프롬프트. 확인 기준일 2026-11-24.

사용 방법

  1. 아래 명령어의 붙여넣기 프롬프트를 복사합니다.
  2. [ ] 안의 내용을 내 작업에 맞게 바꿉니다.
  3. Codex 또는 Claude Code 입력창에 붙여넣고 실행합니다.
  4. 처음 쓰는 명령어는 파일을 수정하기 전에 계획이나 확인을 먼저 요청하세요.

목차

  • A. Codex 명령어 10개
  • B. Claude Code 명령어 20개

A. Codex 명령어 10개

Codex CLI 입력창에 / 를 치면 나오는 명령어입니다.

/init

현재 폴더에 AGENTS.md 틀을 만듭니다.

에이전트 활용: 반복하는 프로젝트 규칙을 한 번 적어 두면 작업할 때 참고합니다.

붙여넣기 프롬프트

/init 을 실행해 AGENTS.md 틀을 만든 뒤, 이 프로젝트의 폴더 구조, 작업 규칙, 금지 사항, 검수 방법을 채워 주세요. 채운 내용을 보여 주고 제가 확인하면 저장해 주세요.

/plan

계획 모드로 전환합니다. 설명을 함께 적으면 그 작업의 계획부터 시작합니다.

에이전트 활용: 실행 전에 계획을 먼저 보고 고쳐서 방향이 어긋나는 것을 줄입니다.

붙여넣기 프롬프트

/plan 이번 작업을 단계별 계획으로 먼저 보여 주세요. 제가 승인하기 전에는 파일을 수정하지 마세요. 작업: [여기에 작업 내용]

/goal

큰 작업의 목표를 저장합니다. 보기, 일시정지, 재개, 지우기가 됩니다.

에이전트 활용: 여러 단계로 나뉜 긴 작업의 목표를 계속 추적합니다.

붙여넣기 프롬프트

/goal [끝 조건을 한 문장으로] 을 설정하고, 조건을 만족할 때까지 진행 상황을 단계별로 보고해 주세요. 조건을 만족하면 멈추고 결과를 요약해 주세요.

/skills

사용할 수 있는 로컬 스킬을 목록으로 보고 고릅니다.

에이전트 활용: 자주 하는 작업 순서를 스킬로 묶어 두고 불러 씁니다.

붙여넣기 프롬프트

/skills 목록을 보고 [작업 이름]에 맞는 스킬이 있으면 골라서 사용해 주세요. 없으면 없다고 알려 주고, 직접 진행할 방법을 제안해 주세요.

/subagents

하위 에이전트 스레드를 바꿔 가며 각 작업의 진행을 봅니다.

에이전트 활용: 나눠 맡긴 작업이 각각 어디까지 왔는지 확인합니다.

붙여넣기 프롬프트

/subagents 로 하위 작업 스레드를 확인하고, 각 스레드가 어디까지 진행됐는지 한 줄씩 정리해 주세요. 막힌 스레드가 있으면 이유를 함께 알려 주세요.

/hooks

실행 전후에 도는 훅을 보고, 새로 생기거나 바뀐 훅을 신뢰할지 정합니다.

에이전트 활용: 에이전트가 자동으로 무엇을 실행하는지 확인합니다.

붙여넣기 프롬프트

/hooks 로 설정된 훅 목록을 보여 주세요. 새로 추가되었거나 바뀐 훅이 있으면 목적과 실행 명령을 설명하고, 제가 승인하기 전에는 실행하지 마세요.

/mcp

연결된 MCP 도구 목록을 봅니다. verbose를 붙이면 서버 정보가 나옵니다.

에이전트 활용: 에이전트가 부를 수 있는 외부 도구가 무엇인지 확인합니다.

붙여넣기 프롬프트

/mcp verbose 로 연결된 MCP 서버와 도구를 보여 주고, [작업 내용]에 쓸 수 있는 도구를 골라 이유와 함께 추천해 주세요.

/permissions

Codex가 묻지 않고 할 수 있는 범위를 바꿉니다.

에이전트 활용: 읽기만 허용할지, 수정까지 허용할지 작업마다 정합니다.

붙여넣기 프롬프트

/permissions 로 현재 허용 범위를 보여 주고, 이번 작업에 필요한 최소 권한만 남겨 주세요. 권한을 바꾸기 전에 먼저 알려 주세요.

/model

모델과 추론 강도를 고릅니다.

에이전트 활용: 가벼운 정리에는 가벼운 설정, 어려운 설계에는 무거운 설정을 씁니다.

붙여넣기 프롬프트

/model 에서 [작업 종류]에 맞는 모델과 추론 강도를 골라 주세요. 고른 이유를 한 줄로 알려 주세요.

/compact

긴 대화를 요약해 토큰 공간을 확보합니다.

에이전트 활용: 긴 작업이 끝난 뒤 핵심만 남기고 이어서 작업합니다.

붙여넣기 프롬프트

/compact 로 지금까지의 대화를 요약해 주세요. 결정 사항, 남은 할 일, 수정한 파일 경로는 빠뜨리지 마세요.

B. Claude Code 명령어 20개

Claude Code 공식 명령어 문서에 있는 명령어 중 에이전트 구축에 필요한 것입니다.

1. 규칙과 권한

/init

프로젝트에 CLAUDE.md 틀을 만듭니다.

에이전트 활용: 반복하는 규칙을 적어 두고 작업할 때 참고하게 합니다.

붙여넣기 프롬프트

/init 을 실행해 CLAUDE.md 를 만든 뒤, 이 프로젝트의 폴더 구조, 작업 규칙, 금지 사항, 검수 방법을 채워 주세요. 채운 내용을 보여 주고 제가 확인하면 저장해 주세요.

/memory

CLAUDE.md를 열어 고치고, 자동 메모리를 켜거나 끄고, 저장된 메모리를 봅니다.

에이전트 활용: 에이전트가 기억하는 내용을 직접 점검합니다.

붙여넣기 프롬프트

/memory 를 열어 CLAUDE.md 에서 [고칠 내용]을 고쳐 주세요. 고치기 전후 내용을 보여 주세요.

/permissions

묻지 않고 허용할 명령, 물어볼 명령, 막을 명령을 규칙으로 정합니다.

에이전트 활용: 에이전트의 행동 경계를 정합니다.

붙여넣기 프롬프트

/permissions 로 현재 허용, 질문, 차단 규칙을 보여 주고, [명령]은 항상 제게 확인받도록 규칙을 추가해 주세요.

/hooks

도구 실행 전후에 도는 훅 설정을 봅니다.

에이전트 활용: 자동으로 실행되는 동작을 확인합니다.

붙여넣기 프롬프트

/hooks 로 설정된 훅을 보여 주고, 각 훅이 언제 무엇을 실행하는지 한 줄씩 설명해 주세요. 실행은 하지 마세요.

2. 계획과 실행

/plan

계획 모드로 들어갑니다. 설명을 함께 적으면 그 작업의 계획부터 시작합니다.

에이전트 활용: 실행 전에 계획을 먼저 검토합니다.

붙여넣기 프롬프트

/plan 이번 작업을 단계별 계획으로 먼저 보여 주세요. 제가 승인하기 전에는 파일을 수정하지 마세요. 작업: [여기에 작업 내용]

/goal

목표 조건을 정하면 조건을 만족할 때까지 여러 턴을 이어서 작업합니다.

에이전트 활용: 끝 조건이 분명한 작업을 맡깁니다.

붙여넣기 프롬프트

/goal [끝 조건을 한 문장으로] 을 설정하고, 조건을 만족할 때까지 진행 상황을 단계별로 보고해 주세요. 조건을 만족하면 멈추고 결과를 요약해 주세요.

/loop

세션이 열려 있는 동안 같은 프롬프트를 반복 실행합니다.

에이전트 활용: 주기적으로 확인해야 하는 일을 맡깁니다.

붙여넣기 프롬프트

/loop [확인할 내용]을 [간격]마다 반복 확인해 주세요. 변화가 있을 때만 알려 주세요.

/rewind

대화나 코드를 이전 지점으로 되돌립니다.

에이전트 활용: 잘못 간 방향을 되돌릴 때 씁니다.

붙여넣기 프롬프트

/rewind 로 [지점]까지 되돌린 뒤, 되돌린 내용과 지금 파일 상태를 알려 주세요.

3. 스킬과 하위 에이전트

/skills

사용할 수 있는 스킬을 목록으로 봅니다. 이름이나 설명으로 걸러 볼 수 있습니다.

에이전트 활용: 쓸 수 있는 스킬을 확인하고 고릅니다.

붙여넣기 프롬프트

/skills 목록에서 [작업 이름]에 맞는 스킬을 골라 사용해 주세요. 없으면 없다고 알려 주세요.

/reload-skills

세션 중에 추가하거나 바꾼 스킬을 재시작 없이 다시 읽습니다.

에이전트 활용: 스킬을 고친 뒤 바로 반영합니다.

붙여넣기 프롬프트

/reload-skills 로 바뀐 스킬을 다시 읽은 뒤, 읽힌 스킬 목록을 알려 주세요.

/list-agents

메시지를 보낼 수 있는 하위 에이전트와 세션을 이름과 함께 봅니다.

에이전트 활용: 여러 에이전트가 있을 때 누구에게 맡길지 확인합니다.

붙여넣기 프롬프트

/list-agents 로 메시지를 보낼 수 있는 대상을 보여 주고, [대상]에게 [내용]을 보내 주세요.

/subtask

대화를 이어받은 하위 에이전트를 만들어 백그라운드에서 작업을 맡깁니다.

에이전트 활용: 본 작업을 멈추지 않고 부분 작업을 나눠 맡깁니다.

붙여넣기 프롬프트

/subtask [부분 작업 설명]을 하위 에이전트에 맡겨 주세요. 본 작업은 계속 진행하고, 끝나면 결과를 알려 주세요.

4. 연결과 자동화

/mcp

연결된 MCP 서버를 보고 다시 연결하거나 켜고 끕니다.

에이전트 활용: 외부 도구 연결 상태를 관리합니다.

붙여넣기 프롬프트

/mcp 로 연결 상태를 확인해 주세요. 끊긴 서버가 있으면 다시 연결하고 결과를 알려 주세요.

/plugin

플러그인을 설치하고, 켜고 끄고, 목록을 봅니다.

에이전트 활용: 필요한 기능을 플러그인으로 추가합니다.

붙여넣기 프롬프트

/plugin list 로 설치된 플러그인을 보여 주고, [기능]에 필요한 플러그인이 있는지 확인해 주세요. 설치는 제가 승인한 뒤에 해 주세요.

/schedule

클라우드에서 정해진 시각에 도는 예약 작업을 만들고 확인합니다.

에이전트 활용: 정기 작업을 자동으로 돌립니다.

붙여넣기 프롬프트

/schedule 로 [작업]을 [요일과 시각]에 도는 예약 작업으로 만들어 주세요. 만들기 전에 내용을 보여 주세요.

/update-config

권한, 환경 변수, 훅 같은 설정 변경을 말로 요청하면 설정 파일을 고쳐 줍니다.

에이전트 활용: 설정 파일을 직접 열지 않고 바꿉니다.

붙여넣기 프롬프트

/update-config 로 [설정 변경 내용]을 적용해 주세요. 변경 전후 내용을 보여 주고 제가 확인한 뒤에 저장해 주세요.

5. 점검과 운영

/context

컨텍스트가 얼마나 찼는지 격자로 보여 주고, 줄일 부분을 제안합니다.

에이전트 활용: 긴 작업 중에 공간이 부족한지 확인합니다.

붙여넣기 프롬프트

/context 로 지금 사용량을 보여 주고, 줄일 수 있는 부분을 알려 주세요.

/compact

대화를 요약해 공간을 확보합니다. 요약에 담을 내용을 덧붙일 수 있습니다.

에이전트 활용: 요약 대상을 지정해 핵심을 남깁니다.

붙여넣기 프롬프트

/compact [요약에 담을 내용: 결정 사항, 남은 할 일, 파일 경로] 로 대화를 요약해 주세요.

/usage

세션 비용과 요금제 사용량을 봅니다.

에이전트 활용: 에이전트를 많이 돌릴 때 사용량을 확인합니다.

붙여넣기 프롬프트

/usage 로 이번 세션의 비용과 사용량을 보여 주세요.

/doctor

설치, 설정, 확장, CLAUDE.md의 문제를 점검하고 고칠 방법을 제안합니다.

에이전트 활용: 에이전트가 이상하게 동작할 때 원인을 찾습니다.

붙여넣기 프롬프트

/doctor 로 설치, 설정, CLAUDE.md 문제를 점검하고 고칠 방법을 적어 주세요. 고치기 전에 제 확인을 받아 주세요.
